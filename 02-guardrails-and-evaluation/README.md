# Guardrails & Evaluation

This directory contains practical implementations and experiments focused on improving the safety, reliability, and evaluation of Large Language Model (LLM) applications.

The projects explore different guardrail mechanisms for controlling LLM inputs and outputs, along with evaluation approaches for assessing the quality and performance of LLM-generated responses.

## Projects

### 1. Guardrails Demo

Exploration and practical implementation of different guardrail approaches used to improve the safety and reliability of LLM applications.

**Topics Covered:**
- NVIDIA NeMo Guardrails
- Guardrails AI
- Llama Guard
- Prompt-Based Guardrails
- Input and Output Validation
- LLM Safety and Content Filtering

### 2. Reference-Based vs Reference-Free Evaluation

A practical comparison of two approaches to evaluating LLM-generated responses.

**Topics Covered:**
- Reference-Based Evaluation
- Reference-Free Evaluation
- LLM-as-a-Judge
- Response Quality Assessment
- Evaluation Metrics and Criteria

## Technologies & Tools

- Python
- Large Language Models (LLMs)
- NVIDIA NeMo Guardrails
- Guardrails AI
- Llama Guard
- Google Colab / Jupyter Notebook

## Objective

The objective of these projects is to understand how guardrails can help mitigate unsafe or undesirable LLM behavior and how different evaluation strategies can be used to assess the quality, relevance, and reliability of generated responses.

## Project Structure

Each project is maintained in a separate directory containing its Jupyter Notebook and a dedicated README with implementation details, dependencies, and instructions for execution.

## Note

These implementations are intended for educational purposes and practical experimentation with LLM safety and evaluation techniques.
