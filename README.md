# agentic_ai_labs


**Exploring and Implementing Modern Agentic AI Systems Through Hands-On Projects**

Welcome to **agentic_ai_labs**, a collection of practical implementations, experiments, and demonstrations focused on Agentic AI, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), advanced retrieval techniques, multi-agent architectures, memory systems, LLM evaluation, guardrails, and observability.

This repository documents my practical learning journey and exploration of modern AI engineering concepts, frameworks, and tools.

## Repository Overview

This repository covers the following areas:

| Area | Topics |
|---|---|
| RAG & Advanced Retrieval | Late Chunking, BM25, SPLADE, ColBERT, Ensemble Retrieval, Self-RAG |
| RAG Evaluation | RAGAS and retrieval evaluation |
| Guardrails & AI Safety | NeMo Guardrails, Guardrails AI, Llama Guard, Prompt-based Guardrails |
| Agent Architectures | Supervisor Pattern, Swarm Pattern, Hierarchical Agents |
| Agent Memory Systems | Working Memory, Episodic Memory, Semantic Memory |
| LLM Evaluation | Reference-Based and Reference-Free Evaluation |
| Tracing & Observability | LangSmith, Langfuse, OpenTelemetry, Arize Phoenix |

## How to Explore

1. Browse the project categories above.
2. Open an individual project folder.
3. Read its README for the objective, implementation details, and setup instructions.
4. Open the Jupyter Notebook in Google Colab or Jupyter Notebook.
5. Configure the required API keys and credentials securely.
6. Execute the notebook cells to explore the implementation.

## Repository Structure

Each project is organized into a dedicated directory containing its notebook and a project-specific README. Additional supporting files and resources are included wherever required.
